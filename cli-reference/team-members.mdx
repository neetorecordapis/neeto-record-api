A team member is a person in your workspace. For fields and response details,
see the [API reference](/api/team-members/list).

## List team members

This command lists the members of the workspace. Pass `--email` to look one up without
paging through the list.

```bash
neetorecord team-members list --email oliver@example.com
```

## Show a team member

This command shows one member.

```bash
neetorecord team-members show aaaabbbb-cccc-dddd-eeee-ffff00001111
```

**Required arguments:**

- `<id>` - the team member id, as returned by `team-members list`.

```json Sample output (--json)
{
  "data": {
    "team_member": {
      "id": "aaaabbbb-cccc-dddd-eeee-ffff00001111",
      "email": "oliver@example.com",
      "first_name": "Oliver",
      "last_name": "Smith",
      "time_zone": "Asia/Kolkata",
      "profile_image_url": null,
      "active": true,
      "organization_role": "Admin"
    }
  }
}
```

## Add team members

This command invites one or more people to the workspace. Repeat `--email` to invite several
at once.

```bash
neetorecord team-members create \
  --email oliver@example.com --email sam@example.com \
  --role Standard \
  --invited-by admin@example.com
```

<TeamMembersCreateFlags />

`--role` must match one of the roles configured on your workspace's Roles page,
and it is case sensitive. Pass `--send-invitation-email=false` to add people
without emailing them.

```json Sample output (--json)
{
  "data": {
    "message": "Users added successfully"
  }
}
```

## Update a team member

This command changes a member's name, email, time zone, or role. Only the flags you pass are
changed.

```bash
neetorecord team-members update aaaabbbb-cccc-dddd-eeee-ffff00001111 \
  --first-name Oliver --last-name Smith --role Admin
```

**Required arguments:**

- `<id>` - the team member id, as returned by `team-members list`.

<TeamMembersUpdateFlags />

The output is the updated team member, wrapped in `data`.

## Delete a team member

This command removes a member from the workspace.

```bash
neetorecord team-members delete aaaabbbb-cccc-dddd-eeee-ffff00001111
```

**Required arguments:**

- `<id>` - the team member id, as returned by `team-members list`.

```text Sample output
Team member removed.
```

Removing the last admin of a workspace is rejected.
