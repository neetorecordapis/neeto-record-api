A tag labels recordings for filtering and search. Tags are created implicitly:
passing a name that does not exist yet to
[`recordings update --tag`](/cli-reference/recordings#update-a-recording) creates
the tag, so there is no separate create command. For fields and response
details, see the [API reference](/api/tags/list).

## List tags

This command lists every tag in the workspace with the number of recordings carrying it. Use
it to check the exact spelling of a tag before passing it to
`recordings update`.

```bash
neetorecord tags list
```
