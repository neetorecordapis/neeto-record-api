These commands manage the CLI itself rather than a NeetoRecord resource.

## Authentication

### login

```bash
neetorecord login --subdomain your-workspace
```

Opens your browser to sign in and saves credentials for the workspace. Omit `--subdomain` to be prompted.

```text Sample output
Authenticated as oliver@example.com on acme.neetorecord.com.
```

### logout

```bash
neetorecord logout --subdomain your-workspace
neetorecord logout --all
```

<LogoutFlags />

```text Sample output
Signed out of acme.neetorecord.com.
```

### whoami

```bash
neetorecord whoami
```

Lists each signed-in account and marks it `(default)` when only one is signed in. Pass `--subdomain <name>` to show one workspace.

```text Sample output
Authenticated as oliver@example.com on acme.neetorecord.com (default).
```

## Diagnostics

### doctor

```bash
neetorecord doctor
```

Checks authentication, API reachability, and the CLI version. See [Troubleshooting](/cli/troubleshooting). When several workspaces are signed in, pass `--subdomain <name>`.

```text Sample output
✓ Authentication: authenticated as oliver@example.com on acme.neetorecord.com
✓ API connection: https://acme.neetorecord.com (responding in 214ms)
✓ CLI version: 1.4.0
```

### version

```bash
neetorecord version
```

Prints the CLI version, commit hash, and build date.

```text Sample output
neetorecord 1.4.0 (commit: a1b2c3d, built: 2026-07-01)
```

### commands

```bash
neetorecord commands
```

Prints the complete command and flag catalog for the installed version as JSON. It is useful in scripts and with AI assistants.

```json Sample output
[
  {
    "command": "neetorecord folders",
    "description": "Manage recording folders",
    "subcommands": [
      {
        "command": "neetorecord folders create",
        "description": "Create a new folder",
        "flags": [
          { "name": "name", "type": "string", "description": "Folder name", "required": true }
        ]
      }
    ]
  }
]
```

## Upgrade

### update

```bash
neetorecord update
```

Updates the CLI to the latest release using the method that installed it. When the binary lives in a Homebrew Cellar it runs `brew update && brew upgrade neetozone/tap/neetorecord`; on other macOS and Linux installs it downloads the shell installer to a temporary file and runs it; on Windows it runs the PowerShell installer. The installers are the same ones the [Installation](/cli/installation) page uses, fetched over HTTPS. The command prints the detected method and the command it runs, and exits non-zero if that command fails.

```text Sample output
Detected Homebrew install.
Running: brew update && brew upgrade neetozone/tap/neetorecord
```

After upgrading, re-run `neetorecord completion <shell>` and any `neetorecord setup` command you use so their files match the new version.

## AI-assistant setup

Add NeetoRecord instructions to your AI coding assistant. See [AI assistants](/cli/ai-assistants) for details.

```bash
neetorecord setup claude
neetorecord setup cursor
neetorecord setup windsurf
neetorecord setup copilot
neetorecord setup gemini
neetorecord setup codex
```

```text Sample output
NeetoRecord plugin extracted to /Users/oliver/.config/neetorecord/claude-plugin

To finish installation, open Claude Code and run these slash commands:
  /plugin marketplace add /Users/oliver/.config/neetorecord/claude-plugin
  /plugin install neetorecord@neetorecord

(Claude Code installs plugins via interactive slash commands - there is no shell equivalent today.)
```

## Shell completion

Shell completion fills in command names, subcommands, and flags when you press `Tab`. It saves you from having to remember the full command tree or look up `--help`.

`neetorecord completion <shell>` installs completion for your shell. For zsh, bash, and PowerShell it writes the script under `~/.config/neetorecord/completions` and adds a marked block to `~/.zshrc`, `~/.bashrc`, or `~/Documents/PowerShell/Microsoft.PowerShell_profile.ps1` that loads it the next time the shell starts. For fish it writes `~/.config/fish/completions/neetorecord.fish`, which fish loads on its own.

<CodeGroup>
```bash Zsh
neetorecord completion zsh
```

```bash Bash
neetorecord completion bash
```

```bash Fish
neetorecord completion fish
```

```powershell PowerShell
neetorecord completion powershell
```
</CodeGroup>

Start a new shell (or run `source ~/.zshrc`) to enable it. After upgrading the CLI, run the command again to update the available completions. Re-running it replaces the existing script and configuration without adding duplicates.

<Note>
  To configure it yourself, pass `--print` to write the raw script to standard output instead of installing it:

  ```bash
  neetorecord completion zsh --print
  ```
</Note>
