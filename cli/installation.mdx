---
title: "Installation"
description: "Install the neetorecord CLI on macOS, Linux, or Windows."
---

Install the `neetorecord` binary with the command for your platform, then [verify it](#verify-the-installation).

<CodeGroup>
```bash macOS
brew trust neetozone/tap
brew install neetozone/tap/neetorecord
```

```bash Linux
curl -fsSL https://neetorecord.com/cli/install.sh | sh
```

```powershell Windows
irm https://neetorecord.com/cli/install.ps1 | iex
```
</CodeGroup>

The shell and Windows installers download the latest release for your architecture (`amd64` or `arm64`), extract it, and add `neetorecord` to your `PATH`.

## Other install methods

<AccordionGroup>
  <Accordion title="macOS - shell script">
    ```bash
    curl -fsSL https://neetorecord.com/cli/install.sh | sh
    ```

    Installs to `/usr/local/bin` and may prompt for `sudo`. To update a Homebrew installation, run `brew upgrade neetorecord`.
  </Accordion>
  <Accordion title="Windows - Command Prompt (CMD)">
    ```cmd
    curl -fsSL https://neetorecord.com/cli/install.cmd -o install.cmd && install.cmd
    ```

    Extracts to `%LOCALAPPDATA%\Programs\neetorecord` and adds it to your user `PATH`. This is equivalent to the PowerShell method.
  </Accordion>
</AccordionGroup>

## Verify the installation

Restart your terminal, then run:

```bash
neetorecord --help
```

You should see the list of available commands. To check the installed version:

```bash
neetorecord version
```

## Upgrade

```bash
neetorecord update
```

The command detects how the CLI was installed and runs the matching upgrade: `brew update && brew upgrade neetozone/tap/neetorecord` for a Homebrew install, the shell installer for other macOS and Linux installs, and the PowerShell installer on Windows. It prints the command it runs and exits non-zero if that command fails. You can also run the install command for your platform again. See [`neetorecord update`](/cli-reference/utility#update).

After an upgrade, re-run `neetorecord completion <shell>` and any `neetorecord setup` command you use so their files match the new version.

<Tip>
  Next, [sign in](/cli/authentication) to a workspace and run `neetorecord doctor`
  to confirm the CLI can reach NeetoRecord.
</Tip>
