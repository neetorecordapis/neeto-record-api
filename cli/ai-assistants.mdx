Use the CLI with an AI coding assistant to manage NeetoRecord in plain language. The `neetorecord setup` commands add NeetoRecord instructions for your assistant, while [`--toon`](/cli/output-formats) keeps command output compact for it to read.

## Set up your assistant

Run the subcommand for the tool you use:

| Command | What it does |
| --- | --- |
| `neetorecord setup claude` | Extracts the NeetoRecord plugin (manifest, marketplace, session-start hook, and skill) to `~/.config/neetorecord/claude-plugin`, replacing any earlier copy. Requires `~/.claude/` to exist. |
| `neetorecord setup cursor` | Writes `.cursor/rules/neetorecord.mdc`. Overwrites the file. |
| `neetorecord setup windsurf` | Writes `.windsurf/rules/neetorecord.md`. Overwrites the file. |
| `neetorecord setup copilot` | Adds a NeetoRecord section to `.github/copilot-instructions.md`. Keeps the rest of the file. |
| `neetorecord setup gemini` | Adds a NeetoRecord section to `GEMINI.md`. Keeps the rest of the file. |
| `neetorecord setup codex` | Adds a NeetoRecord section to `AGENTS.md`. Keeps the rest of the file. |

Every subcommand except `setup claude` writes into the current directory, so run it from the root of the project the assistant works in. The `copilot`, `gemini`, and `codex` commands place their section between `<!-- neetorecord:start -->` and `<!-- neetorecord:end -->` markers and replace that section on re-run instead of adding a duplicate. Re-run the command after every CLI upgrade so the instructions match the installed version.

```bash
neetorecord setup claude
```

`setup claude` prints two slash commands to finish the installation inside Claude Code:

```text
/plugin marketplace add ~/.config/neetorecord/claude-plugin
/plugin install neetorecord@neetorecord
```

After setup, your assistant can check the commands and flags available in your installed CLI version:

```bash
neetorecord commands
```

The command prints the complete catalog as JSON.

## Tips for agent workflows

<Tip>
  Prefer `--toon` when the assistant needs to read a list or record, and
  `--quiet` when it needs to pipe an identifier into the next command. See
  [Output formats](/cli/output-formats).
</Tip>

- Authenticate once with [`neetorecord login`](/cli/authentication); the assistant reuses the stored credentials.
- When several workspaces are signed in, the assistant must pass `--subdomain <name>` on each command.
- Run [`neetorecord doctor`](/cli/troubleshooting) first to confirm the assistant is authenticated and connected.
