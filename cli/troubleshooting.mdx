## Run the doctor

When something goes wrong, start with `neetorecord doctor`. It checks your authentication, API connection, and CLI version.

```bash
neetorecord doctor
```

When multiple workspaces are signed in, name the one to check:

```bash
neetorecord doctor --subdomain your-workspace
```

## Common errors

When a command fails, it prints an error message to standard error and exits with status 1. Usage errors such as an unknown flag or a missing argument add `Run 'neetorecord --help' for usage.`

<AccordionGroup>
  <Accordion title="Not authenticated. Run 'neetorecord login' to authenticate.">
    **Problem**: no workspace is signed in. <br />
    **Solution**: run [`neetorecord login --subdomain <name>`](/cli/authentication).
  </Accordion>
  <Accordion title="Multiple subdomains authenticated (acme, beta); specify --subdomain.">
    **Problem**: more than one workspace is signed in, so the target is ambiguous. <br />
    **Solution**: add `--subdomain <name>` to the command. For `logout`, `--all` signs out of every workspace.
  </Accordion>
  <Accordion title='Not authenticated for "foo". Authenticated subdomains: acme, beta.'>
    **Problem**: the `--subdomain` value does not match any signed-in workspace. <br />
    **Solution**: use one of the listed subdomains, or [sign in](/cli/authentication) to the new one.
  </Accordion>
  <Accordion title="Subdomain not found. Please check that you entered the correct subdomain.">
    **Problem**: `neetorecord login` could not find a workspace at `<subdomain>.neetorecord.com`. <br />
    **Solution**: use the first part of your workspace URL. For `https://spinkart.neetorecord.com`, enter `spinkart`.
  </Accordion>
  <Accordion title="Authentication session expired. Please try again.">
    **Problem**: the browser sign-in was not approved before the session expired. `NeetoRecord CLI authentication timed out after 5 minutes. Please try again.` means the CLI stopped waiting. <br />
    **Solution**: run `neetorecord login` again and approve the sign-in in the browser. If the browser does not open, visit the URL the CLI prints.
  </Accordion>
  <Accordion title="Could not connect to NeetoRecord. Check your internet connection">
    **Problem**: the CLI could not reach the API. <br />
    **Solution**: check your network and run `neetorecord doctor`. If [`NEETORECORD_BASE_URL`](/cli/authentication#environment-variables) is set, confirm it points at a reachable server.
  </Accordion>
  <Accordion title='required flag(s) "xxx" not set'>
    **Problem**: a required flag was omitted. <br />
    **Solution**: check the command's [reference page](/cli-reference/overview) or run `neetorecord <command> --help` for the required flags.
  </Accordion>
  <Accordion title="API error (422): <message>">
    **Problem**: the server rejected the request. The CLI prints `API error (<status>): <message>`, one line per additional error, and a `Suggestion:` line for common statuses: 401 (sign in again), 403 (no permission), 404 (check the ID), 422 (check required fields with `--help`), and 429 (rate limited, wait and retry). <br />
    **Solution**: follow the suggestion. For 401, run `neetorecord login` to refresh the session.
  </Accordion>
  <Accordion title="Claude Code not found (~/.claude/ does not exist).">
    **Problem**: `neetorecord setup claude` requires Claude Code to have been run at least once. <br />
    **Solution**: install and open Claude Code, then run the command again.
  </Accordion>
</AccordionGroup>

## Known API responses

Some requests succeed with a flag set, or fail with a NeetoRecord-specific message:

| Situation | What you see |
| --- | --- |
| A screenshot before the MP4 is ready | `is_screenshot_ready: false`. Run [`recordings trigger-mp4`](/cli-reference/recordings#generate-the-mp4), then retry. |
| A download URL before the MP4 is ready | `is_download_file_ready: false`. Run `recordings trigger-mp4`, then retry. |
| A screenshot timestamp past the end of a recording | `API error (422): Timestamp must be a number between 0 and <duration> seconds.` |
| A screenshot format other than `png` or `jpeg` | `API error (422): Format must be one of: png, jpeg.` |
| A recording request for an email that is not an active member | `API error (422): Could not find active user with the specified email.` |
| Removing the last admin | The request is rejected, because a workspace must keep at least one admin. |

## Check the version

```bash
neetorecord version
```

Prints the CLI version, commit hash, and build date - useful when reporting an issue. To upgrade, run [`neetorecord update`](/cli-reference/utility#update).
