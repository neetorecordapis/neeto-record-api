NeetoRecord hosts the MCP server. There is nothing to install.

| | |
| --- | --- |
| **Endpoint** | `https://connect.neetorecord.com/mcp/messages` |
| **Transport** | HTTP |
| **Authentication** | OAuth, or `Authorization: Bearer YOUR_API_KEY` |

## How each agent connects

| Agent | Sign in with NeetoRecord | API key |
| --- | --- | --- |
| Claude, ChatGPT | Yes | No |
| Claude Code, Codex, Cursor, Gemini CLI, VS Code, Windsurf | Yes | Yes |
| Antigravity | Not documented | Yes |

When you sign in, the assistant sees only what you can see. An API key reaches the whole workspace. See [Authentication](/mcp/authentication).

For the setup steps, see [Connect agent](/mcp/connect).
