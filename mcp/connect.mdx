## Sign in with your NeetoRecord account

<Tabs>
  <Tab title="Claude">
    1. Visit the [NeetoRecord listing](https://claude.ai/directory/neetorecord) in Anthropic's connector directory.

       <Frame caption="The NeetoRecord listing in Anthropic's connector directory.">
         <img src="/assets/mcp/claude-directory-neetorecord.png" alt="The NeetoRecord entry in Claude's connector directory, with a one-line description and a Connect to Claude button" />
       </Frame>

    2. Click **Connect to Claude**.
    3. Sign in to NeetoRecord. See [What the sign-in looks like](#what-the-sign-in-looks-like).

    NeetoRecord then works in claude.ai, the Claude desktop app, Claude mobile, and Cowork.

    If you see **Request** instead of **Connect to Claude**, your Team plan admin must turn NeetoRecord on under **[Organization settings > Connectors](https://claude.ai/admin-settings/connectors)**. After that, click **Connect to Claude**.

    To disconnect, open **[Customize > Connectors](https://claude.ai/customize/connectors)** and remove NeetoRecord.

    <Accordion title="Add it as a custom connector instead">
      Use this only if your organization blocks the connector directory.

      1. Open **[Customize > Connectors](https://claude.ai/customize/connectors)**, click **Add**, then click **Add custom connector**.

         <Frame caption="Add custom connector is the only item under the Add button.">
           <img src="/assets/mcp/claude-add-menu.png" alt="Menu under the Add button in Claude's Connectors settings, with the single item Add custom connector" />
         </Frame>

      2. Enter the name NeetoRecord and paste the server URL.

         ```
         https://connect.neetorecord.com/mcp/messages
         ```

         <Frame caption="The Add custom connector dialog, ready to submit.">
           <img src="/assets/mcp/claude-add-custom-connector-dialog.png" alt="Claude's Add custom connector dialog with the name NeetoRecord and the server URL https://connect.neetorecord.com/mcp/messages filled in, and a Continue button" />
         </Frame>

      3. Click **Continue** and sign in to NeetoRecord.
    </Accordion>
  </Tab>

  <Tab title="ChatGPT">
    1. Go to [chatgpt.com](https://chatgpt.com) and open **Settings → Security and login**.
    2. Turn on **Developer mode**.

       <Frame>
         <img src="/assets/mcp/chatgpt-developer-mode.png" alt="ChatGPT's Developer mode setting, tagged Elevated risk, with its toggle switched on" />
       </Frame>

       If you do not see **Developer mode**, your ChatGPT workspace admin has turned it off. Ask them to allow it.

    3. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins) and click the **plus** button.
    4. In **New Plugin**, enter the name NeetoRecord, set **Connection** to **Server URL**, and paste:

       ```
       https://connect.neetorecord.com/mcp/messages
       ```

    5. Leave **Authentication** on **OAuth**.
    6. Tick **I understand and want to continue**, then click **Create**.
    7. Sign in to NeetoRecord. See [What the sign-in looks like](#what-the-sign-in-looks-like).
  </Tab>

  <Tab title="Claude Code">
    1. Add the server:

       ```bash
       claude mcp add --transport http neetorecord https://connect.neetorecord.com/mcp/messages
       ```

    2. Start Claude Code and run `/mcp`.
    3. Pick **neetorecord** and sign in to NeetoRecord in the browser.
  </Tab>

  <Tab title="Cursor">
    1. Add the server to `~/.cursor/mcp.json`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "url": "https://connect.neetorecord.com/mcp/messages"
           }
         }
       }
       ```

    2. Restart Cursor.
    3. Sign in to NeetoRecord when Cursor asks.
  </Tab>

  <Tab title="Gemini CLI">
    1. Add the server to `~/.gemini/settings.json`. Use `httpUrl`, not `url`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "httpUrl": "https://connect.neetorecord.com/mcp/messages"
           }
         }
       }
       ```

    2. Start Gemini CLI and sign in to NeetoRecord when it asks.
  </Tab>

  <Tab title="Codex">
    1. Add the server to `~/.codex/config.toml`:

       ```toml
       [mcp_servers.neetorecord]
       url = "https://connect.neetorecord.com/mcp/messages"
       ```

    2. Run this command and sign in to NeetoRecord in the browser:

       ```bash
       codex mcp login neetorecord
       ```
  </Tab>

  <Tab title="VS Code">
    You need VS Code 1.99 or later, with GitHub Copilot in **Agent** mode.

    1. Create `.vscode/mcp.json` in your workspace. Use `servers`, not `mcpServers`:

       ```json
       {
         "servers": {
           "neetorecord": {
             "type": "http",
             "url": "https://connect.neetorecord.com/mcp/messages"
           }
         }
       }
       ```

    2. Sign in to NeetoRecord when VS Code asks.
  </Tab>

  <Tab title="Windsurf">
    1. Add the server to `~/.codeium/windsurf/mcp_config.json`. Use `serverUrl`, not `url`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "serverUrl": "https://connect.neetorecord.com/mcp/messages"
           }
         }
       }
       ```

    2. Turn on the server under **Settings → Cascade → MCP Servers**.
    3. Sign in to NeetoRecord when Windsurf asks.
  </Tab>
</Tabs>

### What the sign-in looks like

<Steps>
  <Step title="Connect your workspace">
    Enter your workspace subdomain. For `acme.neetorecord.com`, enter `acme`. See [Workspace subdomain](/mcp/workspace-subdomain).

    <Frame caption="The first screen of the NeetoRecord sign-in.">
      <img src="/assets/mcp/oauth-connect-workspace.png" alt="NeetoRecord dialog headed 'Connect your workspace' with a field for the workspace subdomain, a .neetorecord.com suffix, and a Continue button" />
    </Frame>
  </Step>
  <Step title="Sign in">
    Sign in to that workspace, if you are not signed in already.
  </Step>
  <Step title="Choose what the assistant can do">
    **Read** and **Stay connected** are always on. Tick **Create and update** and **Delete** only if the assistant needs them.

    If your email belongs to more than one workspace, tick each workspace the assistant can reach.

    <Frame caption="Choosing the permissions and the workspaces the connection can reach.">
      <img src="/assets/mcp/oauth-authorize.png" alt="NeetoRecord 'Authorize access' screen showing the workspace and signed-in email, a 'What this connection can do' list with Read and Stay connected always granted and Create and update and Delete as tickable boxes, a 'Workspaces to connect' list with three workspaces, and Cancel and Authorize buttons" />
    </Frame>
  </Step>
  <Step title="Authorize">
    Click **Authorize**.
  </Step>
</Steps>

To add a workspace or a permission later, sign in again and tick it.

## Use an API key

An API key reaches the whole workspace, not only what you can see. Use it for automation. See [Authentication](/mcp/authentication).

<Tabs>
  <Tab title="Claude Code">
    1. Add the server to `~/.claude.json`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "type": "http",
             "url": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer YOUR_API_KEY"
             }
           }
         }
       }
       ```

    2. Restart Claude Code.
  </Tab>

  <Tab title="Cursor">
    1. Add the server to `~/.cursor/mcp.json`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "type": "http",
             "url": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer YOUR_API_KEY"
             }
           }
         }
       }
       ```

    2. Restart Cursor.
  </Tab>

  <Tab title="Gemini CLI">
    1. Add the server to `~/.gemini/settings.json`. Use `httpUrl`, not `url`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "httpUrl": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer YOUR_API_KEY"
             }
           }
         }
       }
       ```

    2. Restart Gemini CLI.
  </Tab>

  <Tab title="Codex">
    1. Add the server to `~/.codex/config.toml`:

       ```toml
       [mcp_servers.neetorecord]
       url = "https://connect.neetorecord.com/mcp/messages"
       bearer_token_env_var = "NEETORECORD_API_KEY"
       ```

    2. Set `NEETORECORD_API_KEY` to your API key in the shell where you run Codex.
  </Tab>

  <Tab title="VS Code">
    You need VS Code 1.99 or later, with GitHub Copilot in **Agent** mode.

    1. Create `.vscode/mcp.json` in your workspace:

       ```json
       {
         "inputs": [
           {
             "type": "promptString",
             "id": "neetorecord-api-key",
             "description": "NeetoRecord API key",
             "password": true
           }
         ],
         "servers": {
           "neetorecord": {
             "type": "http",
             "url": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer ${input:neetorecord-api-key}"
             }
           }
         }
       }
       ```

    2. Paste your API key when VS Code asks.

    <Warning>
      This file lives in your project. Do not paste the key into the file itself, or it can end up in a commit.
    </Warning>
  </Tab>

  <Tab title="Windsurf">
    1. Add the server to `~/.codeium/windsurf/mcp_config.json`. Use `serverUrl`, not `url`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "serverUrl": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer YOUR_API_KEY"
             }
           }
         }
       }
       ```

    2. Turn on the server under **Settings → Cascade → MCP Servers**.
  </Tab>

  <Tab title="Antigravity">
    1. Open **Settings → Customizations → Open MCP Config**.
    2. Add the server to `mcp_config.json`. Use `serverUrl`, not `url`:

       ```json
       {
         "mcpServers": {
           "neetorecord": {
             "serverUrl": "https://connect.neetorecord.com/mcp/messages",
             "headers": {
               "Authorization": "Bearer YOUR_API_KEY"
             }
           }
         }
       }
       ```

    3. Reload Antigravity.
  </Tab>
</Tabs>

Replace `YOUR_API_KEY` with a key from your workspace. [Learn how to generate your API key.](https://help.neetorecord.com/articles/api-keys)

## Confirm the connection

Ask the assistant *"List my five most recent NeetoRecord recordings."* If it answers with your recordings, the connection works. For more prompts, see [Examples](/mcp/examples). If it does not work, see [Troubleshooting](/mcp/troubleshooting).
